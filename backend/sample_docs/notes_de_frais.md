# Gestion des Notes de Frais

Les notes de frais doivent être soumises via l'outil Expensify avant le 5 de chaque mois.
Seuils et limites :
- Repas professionnel : 35€ TTC maximum par invité.
- Hébergement : 120€ la nuitée (150€ pour Paris).
- Transports : Privilégier le train en 2ème classe pour les trajets de moins de 3h.
Tout dépassement doit faire l'objet d'une validation préalable par le directeur financier.
Les reçus originaux (ou photos lisibles) sont obligatoires pour tout montant supérieur à 10€.
