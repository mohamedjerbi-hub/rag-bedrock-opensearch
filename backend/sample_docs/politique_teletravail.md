# Politique de Télétravail 2024

L'entreprise autorise jusqu'à 3 jours de télétravail par semaine pour tous les employés à temps plein, sous réserve de validation par le manager direct. 
Les jours de présence obligatoires sur site sont généralement fixés lors des réunions d'équipe.
Une indemnité de 20€ par mois est allouée pour couvrir les frais liés au télétravail (internet, électricité).
Les équipements de bureau (écran, chaise ergonomique) peuvent être commandés via le portail IT.
