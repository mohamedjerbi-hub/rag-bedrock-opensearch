# Directives de Sécurité Informatique

Les règles suivantes s'appliquent à tous les systèmes d'information :
1. Mots de passe : Ils doivent faire au moins 14 caractères et être changés tous les 90 jours.
2. 2FA : L'authentification à double facteur est obligatoire pour tous les services cloud, y compris AWS et GitHub.
3. VPN : Toute connexion depuis un réseau public doit se faire via le VPN de l'entreprise.
4. Incidents : Tout incident de sécurité (phishing, perte de matériel) doit être signalé immédiatement à securite@entreprise.com.
