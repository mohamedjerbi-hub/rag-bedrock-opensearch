# Processus d'Onboarding

Tout nouvel employé doit suivre le processus d'onboarding sur ses 2 premières semaines.
Semaine 1 : 
- Récupération du matériel (ordinateur, badge).
- Formation sécurité de l'information (obligatoire).
- Présentation de l'entreprise par les RH.

Semaine 2 :
- Formations spécifiques au département.
- Déjeuner d'intégration avec l'équipe.
- Point avec le manager pour définir les objectifs du premier trimestre.
