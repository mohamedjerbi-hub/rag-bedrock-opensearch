# Congés et Absences

Les employés bénéficient de 25 jours de congés payés et de 10 jours de RTT par an.
Les demandes de congés se font via l'outil Lucca. 
Un délai de prévenance d'au moins 2 semaines est demandé pour les congés de plus de 3 jours.
Absences maladie : L'arrêt de travail doit être transmis aux RH sous 48h. L'entreprise maintient le salaire à 100% dès le premier jour d'absence (pas de carence).
